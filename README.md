# al-abbad-preview

This repository is a preview package for the Al‑Abbad Travel website (Arabic RTL). It contains a static HTML/CSS site ready to be deployed to Netlify or served locally for review.

Contents:
- index.html
- styles.css
- assets/ (place your logo images here: logo.png, logo-small.png) -- currently the HTML uses Unsplash placeholders for images; replace them with your images when ready.

How to preview locally:
1. Download the repository or clone it.
2. Open `index.html` in your browser.

How to deploy to Netlify (quick):
1. Create a Netlify account (https://app.netlify.com/).
2. From Netlify Dashboard choose "New site from Git" and connect this GitHub repo, then deploy. Or use Drag & Drop: Sites -> New site from drag & drop -> drop a ZIP of the repo.

Google Form (Booking form):
- The contact page embeds a sample Google Form. To store responses in your Google Sheets, create a Google Form in your Google account with the required fields, then click "Send" > "<>" embed and paste the form's embed URL into the iframe src in index.html (replace the placeholder URL).

Notes:
